확정안 · 2026-08-27

Qwen2.5-Omni
DeltaTok → Caption → QA

S1은 A Frame is Worth One Token의 DeltaTok을 기준으로 단순하게 재현하고, 이후에만 LoRA를 붙인다.

0. 변경하지 않는 원칙

  • Native Qwen2.5-Omni vision/audio encoders와 base Thinker는 항상 freeze.
  • LLM 학습은 LoRA만 사용하고 full fine-tuning은 구현하지 않음.
  • S1에는 action label, caption, QA, class loss를 넣지 않음.
  • Audio와 video DeltaTok은 parameter를 공유하지 않음.
  • 새 vocabulary token은 초기 버전에 추가하지 않음. Continuous type embedding과 외부 commit controller 사용.
  • 세 단계 loss를 동시에 섞지 않고 단계별 gate를 통과해야 다음으로 이동.

1. S1 — Self-supervised DeltaTok

질문: 이전 Omni feature와 하나의 continuous delta token만으로 현재 feature를 복원할 수 있는가?

Frozen target features

video: xᵛ_t = FrozenOmniVision(causal_chunk_t)
audio: xᵃ_t = FrozenOmniAudio(causal_chunk_t)

모든 chunk는 독립적으로 encode해 미래 정보가 이전 feature에 섞이지 않게 한다. 기준 chunk는 2초다.

Tokenizer architecture

x_(t-1), x_t: native 3584-D tokens
        │ shared input projection 3584 → 768
        │ previous/current type embeddings
        ▼
Transformer encoder + learned delta query
        ▼
z_t: K×768 continuous delta token

Decoder(previous tokens, z_t)
        ▼
predicted residual Δx̂_t
        ▼
x̂_t = x_(t-1) + Δx̂_t

첫 실험은 논문과 동일하게 K=1. K=2/4/8은 1-token 결과가 부족할 때만 ablation한다. Video/audio는 동일 설계의 별도 모델이다.

Loss

z_t  = Encoder(x_(t-1), x_t)
x̂_t = Decoder(x_(t-1), z_t)

L_S1 = MSE(x̂_t, x_t)

초기 방법에는 cosine, history, action CE, order classification, recurrent accumulator를 추가하지 않는다. Cosine과 retrieval은 평가 지표다.

축적과 reset

<FULL_V> xᵛ_0
<DELTA_V> zᵛ_1
<DELTA_V> zᵛ_2
...

caption commit → 현재 embedding을 새 FULL로 저장 → 이전 delta sequence 제거

Delta를 recurrent state로 다시 압축하지 않는다. Commit 전까지 시간순 sequence로 append하며 Thinker의 position/TMRoPE가 순서를 표현한다.

학습 protocol

  • AdamW, BF16, exact resume.
  • 논문 기준: 50K iterations, 5K warmup, peak LR 1e-3, weight decay 1e-4, gradient clip 1e-2.
  • Global batch 1,024를 목표로 4×A6000 micro-batch와 gradient accumulation 사용.
  • Previous/current에 동일 spatial augmentation 적용.
  • 여러 temporal offset에서 causal pair sampling.

S1 gate

지표목적
Feature MSE논문의 직접 tokenizer 품질.

Retrieval R@1복원 feature가 올바른 target을 식별하는지 확인.

Autoregressive drift가 실제로 클 때만 논문 부록처럼 자기 reconstruction을 다음 reference로 사용하는 fine-tuning을 추가한다.

2. S2 — Caption LoRA

S1 DeltaTok encoder를 freeze하고 decoder는 사용하지 않는다.

Thinker input = first native full tokens
              + projected ordered video delta tokens
              + projected ordered audio delta tokens
              + modality/type embeddings
              + timestamps

학습 대상과 loss

  • Train: Delta→3584 projector, modality/type embeddings, LoRA_caption.
  • Freeze: native encoders, DeltaTok, base Thinker.
  • L_S2 = autoregressive CE(human caption).

첫 caption 실험은 human ground-truth boundary에서 수행한다. Greedy caption이 causal controls를 통과한 뒤 modality별 CommitHead를 BCE로 별도 학습한다.

S2 gate

실제 greedy generation을 correct/zero/reversed/shuffled/wrong-source delta와 비교한다. Caption NLL만으로 통과시키지 않는다.

3. S3 — Source-disjoint QA LoRA

QA input = generated caption memory
         + active first-full/delta sequence
         + question
  • LoRA_caption freeze.
  • 새 LoRA_QA만 학습.
  • L_S3 = autoregressive CE(answer).
  • Caption 학습 media와 QA media는 source ID/URL/hash 기준 완전 분리.

Caption 기여 비교

Branch학습
Native baselineRaw Omni, QA LoRA 없음.
No-caption controlDeltaTok → QA LoRA.
ProposedDeltaTok → Caption LoRA → QA LoRA.
Raw-input reference같은 LoRA를 raw full Omni input에 적용.

No-caption와 Proposed는 동일 QA split, initialization, optimizer, step 수를 사용한다. Caption masked/shuffled, caption-only, active-delta-only도 평가한다.

S1 audioAudioSet사용 안 함.

서버 inventory에서 Ego4D long-video subset 5,794개(약 1.8TB), VGGSound video/audio/metadata, AudioSet audio가 확인됐다. 새 다운로드 없이 Video S1=Ego4D, Audio S1=AudioSet, synchronized integration=VGGSound로 시작한다. 기존 SSV2 Omni cache는 regression test로만 유지하고 general S1 주 결과에는 사용하지 않는다.

5. 단계 이동 규칙

  1. S1 1-token reconstruction과 rollout이 통과하기 전에는 caption 학습 금지.
  2. S2 greedy caption이 causal controls를 통과하기 전에는 commit policy와 QA 학습 금지.
  3. S3는 caption source와 완전히 분리된 QA source에서만 학습·평가.
  4. 모든 단계는 small integration → long/full training → multi-seed untouched test 순서.
