Factorized ThoughtCodec

Independent modality delta/commit cycles with a bounded cross-modal rendezvous buffer and a separate joint-relation delta lane.

Repository: ccho4702/omnithought Backbone: Qwen2.5-Omni-7B Hardware: RTX 3090 24 GB Pre-review commit: 1b88ec5 Method status: candidate, not validated

Canonical status: falsification before implementation

This is not an approved paper method yet. Private/shared multimodal factorization, asynchronous fusion, residual captions, and modality-specific text summarizers all have close prior work. The current candidate is useful and technically plausible only if four small falsification studies pass. Do not start a full trainer, large download, or long run before those studies.

Candidate hypothesis

Each modality should preserve its own asynchronous temporal changes through a private delta accumulator and scoped text commits, while a short-lived rendezvous buffer retains selected aligned evidence long enough for a separate joint delta lane to capture cross-modal relation changes. Final reasoning uses both private and joint semantic memories.

Private clocksImage, video, and audio commit and reset independently.
Private memoryNo joint fusion may erase modality-exclusive facts.
Joint deltaTracks changes in relations, not the sum of private deltas.
RendezvousPreserves bounded raw evidence until joint reasoning or timeout.

2. Candidate architecture

Figure 1. Private commits persist immediately, while selected residual evidence remains briefly in the rendezvous buffer so delayed cross-modal relations are not forced through text alone.

2.1 Why the rendezvous buffer is necessary

t=1.0 AUDIO: glass shattering → AUDIO commit → audio private reset selected acoustic residual remains in rendezvous for W seconds t=2.0 VIDEO: person picks up transparent fragments → VIDEO commit recent video residual meets retained audio evidence JOINT commit: "The person is picking up the glass that just shattered." relevant rendezvous entries are released

Without the buffer, the joint writer sees only lossy private captions. With an unbounded buffer, the system loses its memory advantage. The buffer is therefore both a semantic and systems requirement.

3.1 Attention contract

  • Overall input can contain all modalities.
  • Private caption content is generated with raw-sensory attention restricted to its own lane.
  • Private writer may attend the initial question and prior semantic text memory.
  • Private writer must not use another raw modality as a shortcut.
  • Joint writer and final answer may attend all semantic lanes and allowed rendezvous evidence.

3.2 Independent clock semantics

Audio: A-anchor → δA → AUDIO commit/reset ─────→ δA → ... Video: V-anchor → δV → δV → δV → VIDEO commit/reset → ... Image: I-anchor ─────────────────→ IMAGE update ─────→ ... Joint: relation anchor → δJ ─────────────→ JOINT commit/reset

One modality committing must never reset another private accumulator. This is the central difference from one omni accumulator.

4. Joint delta: the missing omni lane

Joint delta is not δA + δV. It is the temporal change of a cross-modal relation representation.

RtJ = Fjoint(ztI, ztV, ztA, alignmentt)
δtJ = RtJ − PJ(R<tJ)
AtJ = Update(At−1J, δtJ, recent private commits)

4.1 Relation types

  • Visible source ↔ sound event
  • Action ↔ acoustic onset/offset
  • Speech ↔ lip motion / speaker identity
  • Cross-modal causality and temporal order
  • Complementary disambiguation
  • Contradiction, asynchrony, dubbing, or off-screen evidence

4.2 Joint necessity check

Lnecessity = max(0, margin − log P(CJ|A,V) + max(log P(CJ|A,V′), log P(CJ|A′,V)))

This optional loss applies to the joint lane only. Private delta streams remain intact. A joint commit should become less likely or less correct when either required modality is swapped.

Only potentially defensible contribution

A bounded, asynchronous multi-clock semantic codec that preserves modality-private event memory while retaining only a small rendezvous set of raw residuals for delayed joint-relation commits, and that demonstrably improves the exclusive-event/joint-reasoning/streaming-memory Pareto frontier.

This is a candidate claim, not a proven novelty claim. Strong empirical results and fair prior comparisons are mandatory.

7. Usefulness and validity review

Why it could work

  • Private lanes reduce modality dominance and preserve off-screen audio / visual-only events.
  • Independent clocks match heterogeneous event rates.
  • Text commits can bound long-term semantic memory.
  • Rendezvous evidence avoids forcing every joint relation through private text.
  • Typed commits are interpretable and naturally timestamped.

Why it could fail

  • Text commits may omit exact timing, count, direction, identity, or intensity.
  • Rendezvous buffer may grow or evict evidence before a delayed relation arrives.
  • Separate cycles plus joint processing can cost more than one dense omni pass.
  • Audio latent deltas are technically difficult and may track noise rather than semantics.
  • No public dataset supplies rich private+joint timestamps and final human QA together.

7.2 Best application regimes

  • Long streams with off-screen audio, visual-only events, or asynchronous sensor events
  • Robotics/wearables with missing or delayed modalities
  • Long meetings, surveillance, or egocentric streams where raw KV cannot grow indefinitely
  • Applications requiring provenance by modality

7.3 Weak application regimes

  • Short synchronized clips where dense fusion already fits
  • Coarse QA that does not need private details
  • Tasks where exact raw evidence cannot be replaced by text
  • Cases where delta extraction costs approach full encoder cost

9. Four required falsification studies

Run these before creating delta encoders, cache eviction, or trainers. They test the conceptual assumptions with existing annotations and frozen models.

F1 — Can private captions recover joint facts?

Input: official AVCaps A-only captions + V-only captions Target: official human A+V caption facts Compare: A captions only V captions only A + V private captions official joint caption upper bound

Stop: if private-caption fusion cannot recover a useful fraction of joint facts, private text alone is insufficient and rendezvous evidence is mandatory.

F2 — Does bounded raw evidence add value beyond private text?

Private captions only vs. Private captions + short aligned raw clip/evidence Metric: joint caption factual F1 / joint QA accuracy / modality necessity

Stop or simplify: if raw evidence adds no measurable value, remove the rendezvous mechanism and use private text fusion.

F3 — Do independent clocks beat a shared clock?

Use LLP dense A/V labels without LLM training. Simulate shared 1 s/2 s checkpoints and independent modality boundaries. Report event coverage, delay, commit count, simultaneous-event rate, and expected text cost.

Stop: if independent clocks offer negligible alignment/coverage advantage at matched commit rate.

F4 — Can text memory replace sensory evidence for QA?

Final QA with: full A/V evidence private captions only private + joint captions private captions + bounded aligned raw evidence

Stop: if captions cause a large irrecoverable QA drop and bounded raw evidence does not close it.

9.1 Study order

  1. F1 and F3: annotation-only / low-cost analysis
  2. F2 and F4: frozen-model inference
  3. Only if F1–F4 support the hypothesis: build a deterministic cycle simulator

Simple feature differences, fixed thresholds, exact private reset; no joint lane or training.

Human QA, cost penalties, private/joint ablations, multiple seeds only after one stable seed.

Research no-go

Stop if F1 or F4 shows that private/joint text cannot preserve downstream QA, if F3 shows no independent-clock advantage, or if a bounded rendezvous cannot improve joint reasoning over private captions alone. Do not rescue a failed assumption by adding more modules.

Final summary

The existing repository proves that Qwen2.5-Omni can be QLoRA-tuned on a 3090 to serialize A/V chunks, emit multiple scoped text spans, feed them back, and answer after stream end. It does not prove a novel or effective method. The current candidate preserves modality-private asynchronous memories and adds a bounded raw-evidence rendezvous for joint relation deltas. Its first job is not implementation; it is to survive F1–F4.
